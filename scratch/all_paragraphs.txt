--- P106 [Normal] (bold=True) ---
ABSTRACT

--- P107 [Normal] (bold=False) ---
Modern enterprise networks face diverse cyber threats ranging from massive Distributed Denial of Service (DDoS) assaults to stealthy zero-day exploits, reconnaissance scans, and sophisticated advanced persistent threats (APTs). Traditional signature-based Network Intrusion Detection Systems (NIDS) fail against uncataloged and polymorphic attacks, while naive supervised classifiers suffer from class imbalance and severe alert fatigue. This project presents an end-to-end data mining and machine learning framework for real-time network intrusion and anomaly detection using the benchmark UNSW-NB15 dataset, which contains realistic modern network telemetry encompassing 45 attributes across 9 distinct attack families (Generic, Exploits, Fuzzers, DoS, Reconnaissance, Analysis, Backdoor, Shellcode, and Worms).

--- P108 [Normal] (bold=False) ---
A rigorous, zero-leakage preprocessing pipeline was developed that performs median imputation for numerical features, constant imputation for missing values, and one-hot encoding on categorical protocols, services, and connection states. The preprocessor is fitted strictly on the training partition, transforming 42 raw telemetry attributes into a 187-dimensional feature space. The project implements and compares a dual-engine detection paradigm: (1) a supervised Random Forest Classifier utilizing 100 decorrelated decision trees with balanced class weighting to detect known attack patterns, and (2) a semi-supervised Deep Learning Autoencoder neural network (D -> 64 -> 32 -> 16 -> 32 -> 64 -> D) trained exclusively on benign network traffic to learn normal communication manifolds and identify novel intrusions based on reconstruction error (MSE) thresholding.

--- P109 [Normal] (bold=False) ---
Quantitative evaluation on the holdout benchmark test set demonstrated that the Supervised Random Forest achieved an exceptional F1-score of 0.9150 (Recall: 97.75%, Precision: 86.00%, ROC-AUC: 0.9816, PR-AUC: 0.9860). The Deep Autoencoder, trained without prior exposure to attack signatures, achieved a high normal traffic specificity of 94.08% with a false positive rate of only 5.92% (ROC-AUC: 0.7810), providing a crucial complementary zero-day defense filter. The system explains the Accuracy Paradox in cybersecurity and delivers a responsive Flask-based Security Operations Center (SOC) web application featuring batch CSV prediction, threat consensus alerting (NORMAL, SUSPICIOUS, CRITICAL INTRUSION), and a dataset stream replay simulation engine.

1.1 Problem Statement

--- P116 [Normal] (bold=False) ---
Enterprise computer networks are the backbone of modern commercial, healthcare, and governmental infrastructure. However, the proliferation of sophisticated cyber threats—such as polymorphic malware, automated botnets, zero-day exploits, and targeted data exfiltration—poses an existential challenge to network security. Traditional Network Intrusion Detection Systems (NIDS) rely heavily on signature-matching engines (e.g., Snort, Suricata). This legacy approach exhibits critical operational deficiencies:

--- P117 [Normal] (bold=False) ---
Inability to Detect Zero-Day and Evolving Attacks: Signature-based systems can only recognize previously cataloged threat rules. Attackers easily bypass signatures via packet fragmentation, protocol obfuscation, or minor code mutation.

--- P118 [Normal] (bold=False) ---
High Maintenance and Manual Rule Engineering: Human analysts must continually write and tune thousands of rigid rules, resulting in an unsustainable administrative burden.

--- P119 [Normal] (bold=False) ---
The Class Imbalance Problem and SOC Alert Fatigue: In real-world network traffic, over 95% to 99% of communication flows are benign. Conventional anomaly detectors trigger massive volumes of false alarms (False Positives), causing Security Operations Center (SOC) analysts to suffer alert fatigue and overlook genuine breaches.

--- P120 [Normal] (bold=False) ---
Limitations of Purely Supervised Machine Learning: While supervised classifiers achieve high accuracy on known attack signatures, they have severe blind spots when confronted with entirely novel attack families that were absent from the training set.

--- P121 [Normal] (bold=False) ---
The problem addressed in this project is the design, implementation, and rigorous evaluation of a data-driven Network Intrusion and Anomaly Detection system. The system combines a Supervised Random Forest Classifier with an Unsupervised/Semi-Supervised Deep Learning Autoencoder to detect both known threats and statistical anomalies with high precision, low false alarm rates, and reproducible deployment through a lightweight web dashboard.

--- P122 [Heading 2] (bold=True) ---

--- P123 [Normal] (bold=False) ---
Recent breakthroughs in machine learning and deep learning offer powerful techniques to automate cyber defense. By modeling the underlying statistical patterns of network flow attributes—such as packet timing, byte distributions, TCP state flags, and connection velocity—machine learning models can distinguish between legitimate communication and malicious intrusions.

The UNSW-NB15 benchmark dataset provides an ideal academic testbed for this research. --- P127 [Normal] (bold=False) ---

--- P128 [Normal] (bold=False) ---

2.4 Target Variable & Attack Categories

--- P160 [Normal] (bold=False) ---
The target variable for binary intrusion detection is 'label', where 0 designates legitimate Normal network traffic and 1 designates malicious Attack traffic. In addition to the binary target, the dataset provides an 'attack_cat' attribute classifying intrusions into 9 distinct modern attack families: Generic (cryptographic/algorithmic generic attacks), Exploits (buffer overflows, security vulnerabilities), Fuzzers (randomized protocol fuzzing), DoS (denial-of-service volumetric floods), Reconnaissance (port scans, ping sweeps), Analysis (web app scans, HTML injections), Backdoors (stealthy remote access trojans), Shellcode (executable payloads), and Worms (self-propagating network malware). To prevent target leakage, 'attack_cat' is dropped from feature matrices and used strictly for post-hoc diagnostic evaluation.

--- P161 [Normal] (bold=False) ---
Class label. There is only one class, called “product”, which has index 0. Every one of the 11,787 annotations belongs to this class, so there is no class imbalance, which is a common problem in classification tasks. Everything else in the image, such as shelf edges, price tags and the background, is treated as the background class. The model therefore performs binary classification for each candidate region, deciding whether it contains a product or not. Bounding box. For a region classified as a product, the model must also predict its location, which is a regression task. The box is described by four values normalized between 0 and 1: the x-coordinate of the centre, the y-coordinate of the centre, the width and the height. The labels are stored in one text file per image, with one line per product in the form class_id x_centre y_centre width height. For example, the line 0 0.104167 0.223380 0.070767 0.091601 describes a product centred at about 10.4% of the image width and 22.3% of the image height, which is about 7.1% as wide and 9.2% as tall as the image.

3.1 Missing & Infinite Value Handling

--- P166 [Normal] (bold=False) ---
Real-world network monitoring frequently encounters incomplete captures, packet loss, or numerical overflow. The ingestion module in data_loader.py enforces systematic hygiene:

--- P167 [Normal] (bold=False) ---
Infinite Value Rectification: Network flow rates or loads that involve division by near-zero duration can generate positive or negative infinity (inf, -inf). All infinite numerical entries are replaced with NaN before imputation.

--- P168 [Normal] (bold=False) ---
Numerical Median Imputation: Missing numerical attributes are imputed using the median of each feature, calculated strictly from the training set to remain resilient against extreme power-law outliers.

--- P169 [Normal] (bold=False) ---
Categorical Missing Imputation: In nominal attributes (such as 'service' where '-' designates no application service identified), empty strings and literal 'nan' strings are replaced with standard missing markers ('-').

--- P170 [Normal] (bold=False) ---
UTF-8 BOM Cleansing: The CSV files contain UTF-8 Byte Order Marks (﻿) which can corrupt column names. The loader parses files using 'utf-8-sig' to guarantee exact attribute indexing.

--- P171 [Normal] (bold=False) ---


--- P172 [Heading 2] (bold=True) ---
3.2 Data Cleaning & Leakage Prevention

--- P173 [Normal] (bold=False) ---
Data leakage occurs when information from outside the training partition inadvertently influences feature transformations or model training. The DataPreprocessor class enforces strict separation:

--- P174 [Normal] (bold=False) ---
Target and Identifier Exclusion: The sequential 'id' counter and the outcome proxy 'attack_cat' are immediately decoupled from the feature matrix X, eliminating any possibility of target leakage.

--- P175 [Normal] (bold=False) ---
Whitespace Stripping: Leading and trailing spaces across all nominal cell values and column headers are trimmed to prevent artificial category fragmentation.

--- P176 [Normal] (bold=False) ---
Fit on Train Only: All scaler parameters (mean, variance) and one-hot encoding categories are fitted strictly on the training set. Testing data and streaming inputs are exclusively transformed using frozen parameters.

--- P177 [Normal] (bold=False) ---
Unseen Category Resilience: In real network streams, rare or novel protocols may appear. The preprocessor configures OneHotEncoder(handle_unknown='ignore', sparse_output=False), mapping unseen categories to zero vectors without throwing exceptions.

--- P178 [Normal] (bold=False) ---


--- P179 [Normal] (bold=False) ---


--- P180 [Normal] (bold=False) ---
File Format Check: Only .jpg, .jpeg and .png files are accepted. Other extensions are flagged. 

--- P181 [Normal] (bold=False) ---
Line Format Check: Every label line must contain exactly five values (class, x-centre, y-centre, width, height) and all values must be numeric. 

--- P182 [Normal] (bold=False) ---
Duplicate Box Check: Identical boxes within the same image, compared at four decimal places, are flagged. 

--- P183 [Normal] (bold=False) ---
Cross-Split Leakage Check: Image hashes are compared across the train, validation and test splits. A shared hash means the same image appears in two splits, which would inflate the evaluation results, so any such case triggers a warning status.

4.3 Supervised Classification (Random Forest)

--- P233 [Normal] (bold=False) ---
The first detection engine is a Supervised Random Forest Classifier. Random Forest is an ensemble learning algorithm that constructs 100 decorrelated decision trees using bootstrap aggregating (bagging) and random feature subspace selection. Tree depth is constrained to max_depth = 15 to prevent overfitting on noisy network artifacts. To mitigate class skew between normal and attack records, the model incorporates balanced class weighting (class_weight='balanced'), automatically adjusting tree weights inversely proportional to class frequencies: w_j = N / (2 * N_j). During inference, the ensemble computes continuous attack probabilities: P(Attack | x) = (1 / T) * sum(P_t(Attack | x)). A classification threshold of 0.5 converts probabilities into binary predictions.

4.4 Semi-Supervised Anomaly Detection (Deep Autoencoder)

--- P240 [Normal] (bold=False) ---
Supervised classifiers are blind to novel zero-day attacks that do not match historical training signatures. To address this fundamental limitation, a Semi-Supervised Deep Autoencoder neural network was developed using PyTorch. The Autoencoder is trained EXCLUSIVELY on benign normal traffic (label = 0). The architecture consists of an Encoder compressing the 187-dimensional input into a compact 16-dimensional latent bottleneck (187 -> 64 -> 32 -> 16), followed by a symmetric Decoder reconstructing the flow back to 187 dimensions (16 -> 32 -> 64 -> 187). Each hidden layer utilizes LeakyReLU activations (slope = 0.1) and Batch Normalization. The network optimizes Mean Squared Error (MSE): Loss = (1 / D) * sum((x_i - x_hat_i)^2). Because the network only learns the manifold of benign communication, novel attacks produce elevated reconstruction error. The anomaly threshold tau is calibrated as the 95th percentile of normal training errors.

4.5 Class Imbalance & Evaluation Measures

--- P250 [Normal] (bold=False) ---
In cybersecurity data mining, relying solely on overall accuracy is fundamentally flawed due to the Accuracy Paradox. If 99% of network flows are normal, a trivial classifier predicting 'Normal' unconditionally achieves 99% accuracy yet allows 100% of cyber attacks to compromise the network. Moreover, in UNSW-NB15, while aggregate splits are balanced, sub-categories are severely skewed: Worms (<0.1%) and Backdoors (<0.5%) are heavily overshadowed by Generic and Exploits. Models are therefore evaluated across: Precision = TP / (TP + FP) (alert reliability, minimizing false alarms), Recall = TP / (TP + FN) (attack detection rate), F1-Score = 2 * (P * R) / (P + R) (harmonic balance), Specificity = TN / (TN + FP) (benign traffic retention), False Positive Rate = FP / (FP + TN), and Area Under the ROC and PR Curves (ROC-AUC, PR-AUC).

7.3 Limitations

--- P330 [Normal] (bold=False) ---
1. Offline Dataset Replay vs. Live Kernel Sniffing: The current implementation replays recorded UNSW-NB15 benchmark records rather than capturing live raw Ethernet packets.

--- P331 [Normal] (bold=False) ---

8.1 Conclusion

--- P336 [Normal] (bold=False) ---
This project successfully developed, evaluated, and deployed an end-to-end Network Intrusion and Anomaly Detection system using Python, PyTorch, Scikit-Learn, and the modern UNSW-NB15 benchmark dataset. Following the Knowledge Discovery in Databases (KDD) methodology, raw network telemetry was cleaned, sanitized, and transformed with strict zero-leakage guarantees into a 187-dimensional feature space. The Supervised Random Forest classifier demonstrated exceptional threat detection (Recall: 97.75%, Precision: 86.00%, F1: 0.9150, ROC-AUC: 0.9816). Concurrently, the Semi-Supervised Deep Autoencoder proved highly effective at learning normal traffic representations without prior attack knowledge, maintaining a 94.08% normal specificity and a low 5.92% false positive rate. The system was operationalized as a responsive Flask Security Operations Center (SOC) web application supporting batch CSV prediction and configurable dataset stream replay simulation.
